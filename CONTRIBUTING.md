# Contributing / 贡献指南

Thank you for helping curate **awesome-earth-downscaling**.

## Rules
1. **Verified links only** — do not invent arXiv IDs, authors, years, or URLs.
2. Prefer official project pages / GitHub / arXiv abs pages.
3. Entry format:
   - `**Name** — one-line note (Year) [[arXiv](url)] [[Code](url)] *(venue)*`
4. If unsure, open an issue instead of guessing.
5. Keep bilingual section headers (中文 + English).
6. When adding papers, also append a row to `data/papers.json` when possible.

## Scope
Weather / climate / hydrology **downscaling** (statistical, dynamical, deep learning), with emphasis on DL and NVIDIA Earth-2 / CorrDiff.
